# Backend API Server

This folder runs the FastAPI backend for the IoT Threat Detection and LLM Explanation Service.

## How to Run:

### Option 1 (One-line command):
```cmd
python main.py
```
*(or using the virtual environment: `..\..\.venv\Scripts\python.exe main.py`)*

### Option 2 (Double-click):
Double-click `run.bat` in Windows Explorer.

- **API Base:** `http://127.0.0.1:8000`
- **Swagger Documentation:** `http://127.0.0.1:8000/docs`
