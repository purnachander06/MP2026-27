# Machine Learning Baselines

This folder trains and evaluates centralized machine learning models (Random Forest and Logistic Regression) on the IoT-23 dataset.

## How to Run:

### Option 1 (One-line command):
```cmd
python train.py
```
*(or using the virtual environment: `..\..\.venv\Scripts\python.exe train.py`)*

### Option 2 (Double-click):
Double-click `run.bat` in Windows Explorer.

### To Evaluate Multi-Model Baselines:
```cmd
python evaluate.py
```
